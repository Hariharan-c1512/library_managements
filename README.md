A simple and efficient system to manage a collection of books. This tool allows users to catalog new entries and quickly locate existing titles in the database. 
🚀 Key Features
Add New Book: Seamlessly register new titles by providing a unique Book ID, Title, and Author name.
Search Book: Instantly verify if a book is in the collection.
Success: Displays all book details (ID, Title, Author).
Failure: If the book is missing or the ID is incorrect, the system returns an "Invalid: Book Not Found" message.
